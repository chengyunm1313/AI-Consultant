# 網站視覺重設 v1：流程工作台

## 品牌方向

以「把混亂的 AI 需求整理成可執行流程」為主題，採用墨黑、霧白與訊號黃綠，透過工作台、流程卡、標記與證據物件，呈現徐享的顧問方法與實作能力。

## 享哥 Logo v1

正式標誌以 SVG 重建，不直接使用生成稿：深色圓角方形代表工作台，兩張錯位卡片代表需求與方法，黃綠流程線與節點代表從診斷到交付的連接。網站提供一般版、霧白底反白版與單色版，分別對應導覽列、深色頁尾／深色背景與需要低彩度輸出的情境。

- `brand-mark-v1.svg`：主要品牌標誌。
- `brand-mark-v1-inverse.svg`：霧白底反白標誌。
- `brand-mark-v1-mono.svg`：單色標誌。

Logo 保留「享」字的辨識文字於旁側 lockup，標誌本體維持抽象流程符號，讓它可以獨立用於 favicon、社群頭像與案例標籤，也不會把小尺寸的中文筆畫塞進圖形中。
