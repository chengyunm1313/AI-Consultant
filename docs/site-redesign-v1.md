# 網站視覺重設 v1：流程工作台

## 品牌方向

以「把混亂的 AI 需求整理成可執行流程」為主題，採用墨黑、霧白與訊號黃綠，透過工作台、流程卡、標記與證據物件，呈現徐享的顧問方法與實作能力。

## 享哥 Logo 與完整字標

正式標誌以 SVG 重建，不直接使用生成稿：深色圓角方形代表工作台，兩張錯位卡片代表需求與方法，黃綠流程線與節點代表從診斷到交付的連接。完整字標把抽象流程符號、中文品牌名與英文識別整合在同一個 SVG 中，避免 Header／Footer 以不同 HTML 文字與間距拼接而造成比例不一致。

- `brand-mark-v2.svg`：深色底方形 mark，適合深色背景。
- `brand-mark-v2-inverse.svg`：霧白底方形 mark，適合導覽列與小尺寸使用。
- `brand-lockup-v2-inverse.svg`：Header 使用的霧白底完整字標。
- `brand-lockup-v2.svg`：Footer 使用的深色底完整字標。
- `brand-mark-v2-mono.svg`：需要低彩度輸出的單色 mark。

favicon 與 AEO／結構化資料維持使用方形 mark，完整字標則用於需要清楚呈現品牌名稱的 Header 與 Footer。
