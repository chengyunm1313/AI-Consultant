工具鏈。 這篇會用一個新手能跟上的例子，帶你用 Codex 建立 Void 練習網站，再認識什麼時候才需要研究 Vinext。安裝與指令依本文整理時的官方文件編寫；文章中的範例不是每種環境都已實機驗證，實際操作仍要以所安裝版本的文件為準。 Vite、Void、Vinext、Vercel 和 Cloudflare 有什麼不同？先把幾個常一起出現的名稱分開看： 名稱 主要工作 可以先這樣理解 Vite
