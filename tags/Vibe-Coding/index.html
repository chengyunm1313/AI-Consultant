程式正確，不等於畫面正確。Build、TypeScript 與單元測試可以都通過，但它們不一定會告訴你手機版 CTA 是否被擋住、卡片間距是否一致，或頁面有沒有符合原本的視覺語言。 我現在會把流程拆成不同角色： 1SuperDesign → DESIGN.md → Codex 實作 → Codex Browser 動態驗收 → Playwright 核心回歸 → Deploy
