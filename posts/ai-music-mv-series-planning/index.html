【六首歌如何寫成一季故事？用 ChatGPT、Suno 規劃 AI 音樂 MV】

- 從整季主軸、歌曲 Hook 與風格錨點，到 MV 分鏡提示詞，讓 AI 歌曲和影像有連續感。 -

最近看到有人分享一個 GitHub 開源專案，搭配「金曲獎作詞家秘訣也開源了」這類說法，讓人忍不住想點進去看看。

先說明：目前不能只憑這份文件確認作者具有金曲獎作詞家身分，也不適合把它說成官方作詞秘訣。真正值得看的，是如何先規劃一整季的歌曲與 MV，再一集一集製作。

這個專案叫 autoip-mv-maker。它的 README 介紹的是一套 AI 音樂 MV 製作流程；本文聚焦在其中獨立的系列企劃文件，並把觀念改寫成新手可以用 ChatGPT 和 Suno 練習的步驟。這些提示詞是入門練習，不代表必須先安裝該專案。

以前用 AI 寫歌，常常是想到一個主題，就請它「寫一首關於失戀的歌」，再把歌詞交給音樂生成工具。第一首完成後，下一首又從零開始想，歌與歌之間未必有關聯。

另一種做法是先規劃整個系列：六首歌可以各自成立，也能依序講完一段故事。第一首相遇、第二首曖昧、第三首告白，直到最後一首重逢。當故事主軸、角色、音樂特色和畫面方向先有共識，後續寫歌詞、生成歌曲與安排 MV 都比較容易接起來。

先認識這個 GitHub 專案與系列企劃文件

GitHub 專案本身涵蓋歌曲分析、分鏡、影像生成、剪輯、字幕與上架素材等 MV 製作流程；SERIES_PLANNING.md 則是規劃一季內容的文件。兩者的用途不同：你可以先讀系列規劃文件、用 ChatGPT 和 Suno 做創作練習；如果之後要執行專案中的完整自動化流程，再依 README 準備需要的環境。

初學時先搞懂這幾個詞就夠了：

名詞 白話解釋
GitHub 放置程式碼與開源文件的平台
Prompt 你交代 AI 工作的指令
Hook 歌曲中容易被記住、可能反覆出現的一句歌詞或旋律
Suno 可依文字描述生成歌曲的 AI 音樂工具
系列企劃 開始做第一首歌前，先定義整季的故事與共同特色

第一步：替整季歌曲定主軸

系列企劃文件建議先用一句話說明整季，再找一條能把各集排出順序的主軸，接著挑出幾個跨集固定的風格錨點，並為每集寫企劃卡。季數、題材與故事結局都可以自行決定；文件中的 4 到 8 集只是系列規劃的例子。

例如：

都市愛情流行 × 六首歌，每首歌推進兩個人之間的距離，從相遇走到重逢。

這句話同時交代題材、形式、集數和故事變化方向。接著可以把六首歌排成一條故事線：

集數 歌曲概念 故事位置 可發展的 MV 畫面
EP01 那天的雨 雨天第一次相遇 捷運出口、雨傘、街燈
EP02 多走一站 兩人開始曖昧 一起搭車、錯過下車提醒
EP03 我想告訴你 終於鼓起勇氣告白 夜晚散步、停在路口的對話
EP04 沒說出口 誤會讓兩人分開 沒有送出的訊息、空下來的座位
EP05 你的城市 分開後各自生活 兩個城市、相似的雨景
EP06 還好是你 多年後再次相遇 熟悉的街角、再次撐起的雨傘

每首歌都可以自己聽，但角色與事件會逐步往前走。除了愛情故事，也可以用季節、一天的時間、人物選擇、距離變化或逐步揭曉的線索當主軸。

用幾個穩定錨點保留系列感

系列企劃文件把固定項目稱為「錨點」。你可以挑 3 到 5 個跨集保留，例如：同一組主角、固定的歌曲段落結構、某個反覆出現的物件、相似的 MV 畫面語言，或固定的縮圖與標題格式。其他項目仍可依每首歌的故事調整。

這樣做是為了讓觀眾感覺「這些作品屬於同一個系列」，不代表每首歌都要使用一模一樣的曲風、場景或旋律。

四種可以自行採用的歌曲敘事練習

以下是把系列故事轉成歌曲的創作方式，供新手練習；它們不是原專案規定的固定結構。

練習方式 怎麼使用 簡單例子
問答式 讓前後兩首歌互相回應 男生唱「如果那天我沒有轉身，你會不會等我？」；下一首由女生回答「我其實一直都在等。」
變形 Hook 保留熟悉句型，依劇情改變結尾 「如果時間能夠重來」，從「我還是會遇見你」變成「我依然會選擇你」
章回式 每首歌代表故事的一個階段 相遇、靠近、衝突、分開、重新選擇
首尾呼應 讓最後一首回到第一首的場景或意象 開場在雨中相遇，結尾多年後又在雨中相逢

新手可以先試「章回式＋變形 Hook」：前者幫你排故事順序，後者讓觀眾在不同歌曲裡聽到熟悉的線索。實際創作時仍要讓旋律、節奏和編曲有變化，避免每首歌聽起來只是同一首歌的改寫。

第二步：先請 ChatGPT 規劃歌曲清單

先不要一次寫完六首歌詞。打開 ChatGPT，請它先做系列企劃卡，讓你確認故事方向、歌曲情緒與畫面是否合理。

提示詞：規劃一季歌曲

收到企劃後，先檢查每一集是否真的改變了故事狀態。例如第二首是否讓兩人更靠近、第四首是否有足以造成衝突的事件、最後一首是否回應前面留下的問題。若只是六首歌都在重複「很愛你、很想你」，就回頭調整主軸或每集企劃卡。

第三步：挑一首歌，分段寫歌詞

先挑 EP01 試做，確認角色、語氣與 Hook 是否自然，再把相同的系列設定帶到下一首。提示詞可以像這樣：

提示詞：寫第一首完整歌詞

Verse 是主歌、Pre-Chorus 是預副歌、Chorus 是副歌、Bridge 是橋段、Outro 是結尾。這些標籤可以協助描述歌曲段落，但生成結果仍要實際聽過再調整。

第四步：把歌詞交給 Suno 生成歌曲

打開 Suno，使用目前介面中可以自行輸入歌詞與音樂描述的創作方式。按鈕名稱與功能可能隨平台更新而變動；先確認現在的介面支援你要使用的輸入方式。

準備三項內容：

  1. Title：例如「那天的雨」。
  2. Lyrics：貼上整理好的歌詞和段落標籤。
  3. Style：描述曲風、樂器、情緒與演唱方向。

生成後先聽歌詞是否順口、Hook 是否記得住、情緒是否符合這一集。若不滿意，先找出問題來自歌詞、旋律、演唱或編曲，再針對該項修改，不必立刻把整首歌全部推倒重來。

第五步：整理系列風格設定

在繼續做 EP02 前，把整季固定的錨點整理成一份 style.md。不需要把所有細節鎖死；保留幾個跨集共同點，讓每首歌仍有自己的變化。

提示詞：建立系列風格設定

相同的曲風文字不保證每次生成都會得到完全相同的歌聲或編曲。若你需要較一致的人聲，請依目前平台提供的設定測試，並以實際生成結果為準。

第六步：從歌曲企劃發展 MV 分鏡

先完成歌曲，再把故事和歌詞拆成畫面。初學可以先用簡單流程：

歌曲 → 故事分鏡 → 角色參考圖 → AI 影片片段 → 剪輯成 MV

以 EP01《那天的雨》為例，可以從下列畫面開始：

分鏡 畫面內容
01 台北雨夜，行人穿過捷運站出口
02 男主角走出車站，發現有人在屋簷下躲雨
03 他把雨傘往對方身邊移了一點
04 兩人在街燈下對視，音樂進入副歌
05 女主角離開，男主角回頭看向她的方向

提示詞：把歌曲轉成 MV 分鏡

依照歌曲時間安排畫面，也要考慮生成片段可能需要裁切、延長或重新剪接。不要期待每段 AI 影片剛好符合節拍；最後仍要在剪輯軟體中調整鏡頭長度、音樂進點與轉場。

進階：再考慮使用完整 MV 自動化專案

如果只是練習系列企劃、寫歌詞和生成歌曲，可以先不下載或安裝 autoip-mv-maker。若要實際執行該專案，請先讀取它的官方 README：目前文件提到 AutoIP API、ffmpeg、字型與 API key 等前置條件，生成影像任務會使用點數。請在送出前查看靜圖與成本資訊，並依專案文件保管 API key；不要把 key 寫進一般檔案或貼進提示詞。

開始前，先確認這四件事

  1. 用一句話說清楚整季的題材與變化方向。
  2. 每首歌都有自己的故事位置，而不是重複同一種情緒。
  3. 選出 3 到 5 個跨集錨點，其他細節保留變化空間。
  4. 先完成一首歌和一支 MV 的分鏡，再決定如何延伸整季。

AI 可以幫忙發想、整理和生成素材，但歌曲是否自然、故事是否說得通、角色是否連貫，仍要由創作者檢查。製作或發布作品前，也要確認歌曲、角色圖、字型與其他素材的使用權，並遵守所用平台的內容揭露規範。

常見問答 (FAQ)

Q1：這個專案證實作者是金曲獎作詞家嗎？

不能只憑系列企劃文件確認作者具有金曲獎作詞家身分。本文聚焦的是文件中的系列規劃方法，不把網路貼文的說法當成已證實事實。

Q2：只用 ChatGPT 和 Suno 練習，需要安裝 GitHub 專案嗎？

不需要。你可以先用 ChatGPT 整理故事與歌曲企劃，再用 Suno 試做歌曲；若要執行 autoip-mv-maker 的完整 MV 流程，才依官方 README 準備 API、ffmpeg、字型等環境。

Q3：把相同的 Style 提示詞貼給 Suno，就能固定歌手聲音嗎？

不能保證。相同的描述可能產生不同的聲音或編曲；可依平台當前提供的聲音或延續功能測試，並以實際生成結果確認。

Q4：一定要做六首歌，才能叫音樂系列嗎？

不一定。六首只是本文的示範規模。你可以依故事調整集數，重點是有清楚的共同主軸，並讓每一集既能獨立欣賞，也能推進整體內容。
