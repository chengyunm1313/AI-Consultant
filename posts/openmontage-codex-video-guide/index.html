OpenMontage 教學：一句話讓 Codex 幫你製作影片！從劇本、分鏡到配音與剪輯

以前用 AI 做影片，你要自己當編劇、導演、剪輯師；現在，連製片流程都可以交給 AI Agent 協助！

最近在 GitHub 發現一個很值得研究的開源專案，叫做 OpenMontage。

它不是另一個影片生成模型，而是一套可以搭配 Codex、Claude Code 等 AI Coding Agent 使用的自動化影片製作系統。

簡單來說，你只要告訴 AI：

幫我製作一支 30 秒的商品宣傳短片。

AI 就能依照工作流程，協助完成題材研究、劇本撰寫、角色與場景規劃、分鏡設計、素材取得、配音、剪輯與影片輸出。

更有趣的是，你還可以提供一支喜歡的 YouTube Shorts 或 Reels，讓 AI 分析它的敘事結構與剪輯節奏，再規劃一支原創影片。

對於正在製作 AI 網紅、AI 短劇、商品帶貨影片，或希望用 Codex 自動化剪輯的朋友，這套工具相當值得研究。

這篇文章就帶大家認識 OpenMontage，了解安裝與操作流程，並提供可以交給 Agent 使用的短影音提示詞。

版本與實測範圍：本文依 2026 年 11 月查閱的公開文件整理，教學提示詞為作者延伸設計，尚未逐一完成端到端實機測試。官方網站目前介紹 Windows 版 OpenMontage Studio，標示為私人 Alpha；本文安裝章節介紹的是 GitHub 原始碼工作流程。桌面產品、原始碼與其他同名儲存庫的功能及指令，請分別以各自文件為準。

一、OpenMontage 是什麼？如何讓 AI Agent 協調製片？

OpenMontage 是一套開源的 Agentic Video Production System，也就是「代理式影片製作系統」。

它的核心概念，是把傳統影片製作團隊的工作流程拆解成多個階段，再交由 AI Agent 協調執行。

根據 GitHub 主專案 的介紹，目前包含多種影片製作 Pipeline、100 多種製作工具，以及 700 多份 Agent Skill 與製作知識檔案；數量會隨版本變動。它也整合圖片、影片、語音與素材服務，提供 Remotion、HyperFrames、FFmpeg 等合成與後製路徑，以及 Backlot 分鏡與進度工作台。

最重要的是，它可以搭配 Codex、Claude Code、Cursor 等能讀取檔案與執行程式碼的 AI Coding Agent 使用。

這代表我們不需要每個步驟都親自切換不同工具，而是可以讓 Agent 根據任務，選擇合適的製作流程。

例如，想製作科技知識影片，可以使用圖片、旁白與動態圖表；想製作城市紀錄片，則可以優先搜尋現有的動態素材，而不一定要花錢生成影片。

OpenMontage 的價值，是把不同工具組織成一個可以協作的製片團隊。

二、OpenMontage 能製作哪些影片？

OpenMontage 不只支援 AI 動畫，也涵蓋多種常見的影片製作情境。以下整理主專案 README 列出的工作流範例，並非固定不變的完整清單。

影片類型 適合應用
Animated Explainer 知識型短影音、教學解說
Animation 動態圖文、品牌動畫
Avatar Spokesperson AI 虛擬人物口播
Cinematic 電影預告、品牌形象影片
Clip Factory 從長影片擷取並排序短影音精華
Documentary Montage 紀錄片、素材混剪
Hybrid 真人影片搭配 AI 素材
Localization & Dub 多語言配音與字幕
Podcast Repurpose Podcast 轉短影音
Screen Demo 軟體操作教學
Talking Head 人物講解、Vlog、訪談

其中我認為有三個方向特別值得關注。

AI 短劇：從故事構想到鏡頭規劃

你可以讓 AI 從故事構想開始，規劃人物、場景、鏡頭，再使用合適的影片生成模型製作素材。

商品帶貨：把商品照片變成廣告企劃

例如提供商品圖片，讓 AI 設計廣告腳本、商品特寫、場景與剪輯節奏，最後輸出適合 Instagram Reels 或 YouTube Shorts 的直式影片。

長影片轉短影音：讓既有內容重新發揮價值

對講師、自媒體經營者與 Podcast 創作者來說，這個應用很實用。我們可能已經有一小時的演講影片，卻沒有時間逐段尋找精華；這時就能利用 Clip Factory 工作流，協助分析內容、擷取片段並重新剪輯。

不過，Pipeline 的實際效果仍取決於輸入素材、可用模型與安裝環境，不代表每種影片都能完全無人介入完成。

三、核心工作流程：從研究到影片合成的七個階段

一般使用影片生成模型，可能只需要輸入提示詞，等待模型輸出幾秒鐘的影片。但 OpenMontage 的設計更接近真正的製片流程。

主專案將共同工作流整理為：

  1. 研究：了解題材、受眾與參考影片。
  2. 企劃：決定影片方向、製作方式與成本。
  3. 劇本：撰寫故事、旁白與對白。
  4. 分鏡：安排鏡頭、場景與時間。
  5. 素材：取得圖片、影片、配音與音樂。
  6. 剪輯：整理素材、調整節奏與轉場。
  7. 合成：完成影片輸出與品質檢查。

每個階段都有對應的 Skill 與工作規則。AI 應該先確認影片類型、長度、畫面比例與製作預算，再進行素材製作；實際執行仍應讀取所選 Pipeline 的 manifest 與階段規則。

這個設計很重要。AI 影片製作的問題，往往不只是模型能力，也包括缺少可以反覆執行、修改與驗收的標準流程。

如果某個鏡頭的角色不一致，應該針對該鏡頭重做；如果旁白時間太長，應該先調整劇本與剪輯節奏。這也是 Agent 工作流和單純使用影片生成工具的主要差別。

四、Backlot 分鏡工作台：生成之後，先審核再合成

我覺得 OpenMontage 很值得注意的一項設計，是 Backlot Living Storyboard。

它把影片製作進度顯示在本機工作台，你可以查看劇本、場景、素材生成狀態，以及服務選擇與成本紀錄。素材審核則讓你在正式合成前，先檢查人物長相、服裝、場景與畫面是否符合需求。

這對 AI 網紅影片尤其重要。因為我們最怕的就是：第一個鏡頭人物長得很漂亮，第二個鏡頭卻變成另外一個人！

透過分鏡審核，至少可以提早發現部分一致性問題，但它本身不會保證生成結果一致。

七、進階實作：15 秒 AI 網紅搞笑反轉短劇

接下來才是我真正感興趣的部分。

最近我一直在研究，如何讓 AI 網紅演出 15 秒或 30 秒的幽默反轉短劇，例如美女日常、第一人稱跟拍、對話誤會、最後突然反轉。

這種影片看起來簡單，卻很考驗劇本節奏。尤其要在 15 秒內完成開場、鋪陳與笑點，並不容易。可以先讓 OpenMontage 負責製作規劃，再搭配適合的影片模型生成畫面。

提示詞範例：15 秒搞笑反轉短劇

OpenMontage 可以協調製作流程，但不能保證影片模型生成的人物完全一致。角色一致性仍需透過參考圖、人物設定、分鏡設計與生成後檢查提高成功率。

像 Google Flow 這類網頁工具，也不代表能直接透過 OpenMontage 原生操作。整合前需要另外確認 API、Adapter 或人工交接方式。

九、OpenMontage 可以免費使用嗎？成本要怎麼算？

OpenMontage 本身是開源軟體，也有不需要付費影片生成 API 的製作方式，但不代表所有影片都能免費生成。

工具或來源 用途與注意事項
Piper TTS 本機文字轉語音，需確認語音模型、語言支援與授權
FFmpeg 影片剪輯、混音與轉檔
Remotion 程式化影片合成，實際使用仍應確認適用授權
HyperFrames 動態圖文與動畫合成
Archive.org 開放與典藏影音來源，逐項確認權利資訊
Wikimedia Commons 開放媒體素材，依檔案確認授權與署名要求
Pexels／Pixabay 免費素材來源，部分存取功能需要 API Key

例如，使用現有素材、文字動畫與本機配音，就有機會在不使用付費影片生成 API 的情況下完成作品。

但如果希望生成高品質真人 AI 影片，可能需要搭配 Kling、Veo、Seedance、MiniMax 等雲端模型。實際可用整合、費用、片長與解析度，依模型版本與供應商而異。Coding Agent 本身的訂閱或 API 使用、本機運算，也應納入成本考量。

專案提供成本追蹤、預算與審核相關機制；仍應請 Agent 根據當前版本確認可執行的限制，不要把提示詞中的預算要求當成服務端絕不超支的保證。

我建議初學者先設定每支影片的預算上限，要求付費生成前取得同意。另外，免費素材不代表全部都能無條件商用，仍要檢查每項素材與工具的授權條款。

十、OpenMontage 和 Google Flow、Seedance 有什麼不同？

這些工具的主要角色不同，可以放在同一條製作流程中理解：

工具 本文中的主要定位
Google Flow AI 影片生成與創作介面
Seedance AI 影片生成模型
OpenMontage AI Agent 影片製作流程與工具協調
Remotion 程式化影片合成
FFmpeg 影片與音訊處理

例如，可以使用 Seedance 生成角色演出素材，再交給 OpenMontage 工作流管理後續剪輯與合成；或先由 OpenMontage 規劃劇本、分鏡及成本，人工使用 Google Flow 產出素材，最後交回 Agent 後製。

這些是混合式工作流的構想，自動化程度取決於 API、Adapter 與實際環境，不是每項工具都能直接串接，也不代表本文已測試全部組合。

十一、最值得學習的 Skill 架構：把製片經驗變成工作規則

研究這個專案時，我最感興趣的其實不是它支援多少個影片模型，而是它如何使用 Skill，把製片經驗變成 AI 可以重複執行的規則。

編劇要知道故事結構，導演要安排鏡頭，剪輯師要控制節奏，製片要管理成本。若把所有專業寫成一段超長提示詞，任務變複雜後很容易失去控制。

拆成獨立 Skill，就可以讓 Agent 根據階段讀取對應規則。例如，我們可以進一步設計自己的 AI 短劇工作流：

每個 Skill 負責自己的專業；需要執行程式碼的部分，再交給 Scripts 處理，例如素材整理、影片合併、字幕產生、音量檢查與批次輸出。

這種架構也可以延伸到漫畫、條漫、AI 動漫 MV、Podcast 與數位行銷素材生產。未來更換影片模型時，有機會保留製作流程，再調整生成工具或整合元件；實際仍需重新驗證新模型的輸入、輸出與品質限制。

這才是我認為 OpenMontage 真正值得研究的地方。

十二、使用前要注意哪些限制？

雖然功能很吸引人，我不建議一開始就把所有製片工作全部交給它。

首先，這是持續開發中的開源專案，安裝環境、API 整合與穩定性都需要實測。

其次，Agent 可以協助檢查影片，但自動品質檢查不等於人類的創意判斷。影片是否有趣、故事是否感人、笑點是否成立，仍需要創作者把關。

另外，主專案標示採用 GNU AGPLv3。如果要修改、散布，或透過網路提供修改後的程式服務，應先閱讀完整授權，依實際用途確認義務；第三方工具、語音模型與素材也有各自條款。

最後，建議使用隔離的開發環境測試，安裝前先檢視原始碼與相依套件，不要把 API Key 寫進提示詞或提交到 GitHub。

十三、從操作影片工具，走向管理 Agent 製片流程

過去學 AI 影片製作，常常是在學不同工具的操作方式：今天學 Google Flow，明天研究 Seedance，後天又出現新的生成模型。

當工具越來越多，真正的瓶頸就不只是影片生成能力，而是如何把它們整合成可以持續生產內容的工作流程。

OpenMontage 提供了一個值得參考的方向，讓 Coding Agent 從寫程式，延伸到企劃、編劇、分鏡、素材生成、剪輯、合成與品質檢查。

對我來說，下一步最想測試的是：能不能讓 AI 每天自動提出十個搞笑反轉短劇，挑選三個完成分鏡，再依預算生成影片，最後輸出適合社群平台的短影音？

如果流程能穩定運作，經營 AI 網紅、品牌短劇與商品帶貨內容，就有機會從「一支一支製作」，逐漸轉變成「管理一條 AI 內容生產線」。

但創意方向、角色定位與最後的作品品質，必須有人負責。

AI Agent 讓你有機會從影片操作者，轉變成整個 AI 製片流程的管理者。這才是我最期待的改變。

常見問答 (FAQ)

Q1：OpenMontage 和 Codex 是什麼關係？

OpenMontage 提供影片工作流、Skill 與工具，Codex 則是讀取規則、檢查環境並協調執行的 AI Coding Agent。它不是新的影片生成模型；製作前仍需確認實際可用的工具、素材、模型與成本。

Q2：沒有付費 API Key，也能製作影片嗎？

可以先嘗試現有素材、動態圖文、本機配音與影片合成的路徑，前提是相關工具與語音模型已安裝且適用。雲端影片生成、Coding Agent 使用及運算可能另有成本，工具與素材授權也需要各自確認。

Q3：OpenMontage 能保證 AI 網紅長相一致，或直接控制 Google Flow 嗎？

不能保證。人物一致性仍取決於參考圖、生成模型、鏡頭設計與人工審核；Google Flow 等網頁工具是否能自動操作，也要看實際 API 與整合方式。可先讓 Agent 規劃，再以人工產出素材並交回後製，但這需要明確設計交接流程。
