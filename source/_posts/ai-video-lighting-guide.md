同樣是 AI 生成的人物，有些畫面像電影，有些卻像塑膠公仔。提示詞明明寫了「電影級畫質、超高解析度、專業攝影」，成品還是少了想要的氛圍。

很多時候，差別不只在模型，而在光線有沒有說清楚。

我最近看到一張整理八種電影打光技巧的圖片，裡面提到頂光、逆光、丁達爾光、蝴蝶光、柔光、硬光、側光和底光。這也讓我想到，學會生成圖片與影片之後，還可以補一些真正的攝影知識：什麼光線適合什麼情緒，畫面為什麼看起來立體，觀眾又會先注意到哪裡。

AI 可以幫忙生成畫面，但我們仍需要判斷什麼畫面好看、光線是否合理，以及它想說什麼故事。這篇就從八種常見光線開始，再介紹三點布光、倫勃朗光與適合新手的練習方式。不必先買攝影燈，也不需要背完所有術語；有常用的 AI 圖片或影片工具，就能開始比較練習。

## 為什麼光線會改變畫面情緒？

想像一位女生獨自坐在房間裡看手機。人物、服裝與場景都不變，只調整光線：溫暖柔光可能讓畫面顯得療癒；窗邊側光像是在思考；強烈逆光能做出人物即將登場的感覺；手機從下方照亮臉部，則可能變得詭異。

打光不只是把人物照亮，也能引導注意力、塑造立體感，並傳達故事情緒。開始下提示詞前，可以先想五件事：

1. **方向**：光從正面、側面、背面、上方還是下方照來？
2. **軟硬**：陰影邊緣是柔和漸層，還是清楚銳利？
3. **強度與對比**：亮部和暗部差多少？陰影要保留多少細節？
4. **色彩**：光偏暖、偏冷，還是冷暖混合？
5. **來源**：畫面中的光從哪裡來，方向是否符合場景？

柔光不等於亮度弱，硬光也不等於亮度強；兩者主要描述陰影的過渡方式。陰天的天空像大型柔光源，直射的中午陽光則容易形成邊界清楚的影子。畫面偏暖或偏冷，也會受到光源、白平衡和後製調色影響。鎢絲燈約 3200K、日光常以約 5600K 作為參考，但實際色溫會因光源而異。

「動機式打光」（Motivated Lighting）則是讓光線看起來有合理的場景來源。例如沒有窗戶、也沒有開燈的房間裡，人物臉上若出現一大片強烈陽光，觀眾可能會覺得不自然。因此，除了寫「側光」，也可以交代「午後光線從人物左側窗戶照入」。

## 八種常見光線：先看方向與陰影

這八種名稱不是同一種分類。頂光、逆光、側光和底光描述方向；柔光、硬光描述陰影性質；蝴蝶光是人像布光模式；體積光則描述光束在霧、塵等介質中可見的效果。它們可以搭配使用，不必八選一。

### 01｜頂光：壓迫、權力與孤獨

光從上方照下來，眼窩和下巴容易形成陰影，人物可能顯得嚴肅或有壓迫感。可用於審問、懸疑、黑幫或角色陷入困境的場景。

```text
一位身穿黑色西裝的中年男性獨自坐在昏暗會議室中央，頭頂唯一的吊燈向下照射，額頭和肩膀較亮，眼窩與下巴留下深色陰影，背景逐漸隱入黑暗。
```

### 02｜逆光：輪廓、希望與登場感

光源位於人物後方，頭髮或衣物邊緣可能形成明亮輪廓。若正面沒有補光，人物也可能成為剪影。可用於英雄登場、夕陽告別或故事轉折。

```text
一位披著長披風的劍客站在山頂迎向夕陽，金色逆光勾勒頭髮與披風邊緣，正面保留少量柔和補光，遠方雲海翻騰。
```

### 03｜體積光：讓光束在空氣中可見

陽光穿過森林、霧氣中的車燈，或教堂窗戶投下的光束，都是常見的影像效果。電影與電腦圖學常用「體積光」（Volumetric Lighting）、「God Rays」或「Light Shafts」描述這類可見光束。

「丁達爾效應」是光被微粒散射的物理現象，常被創作圈用來形容光束穿過薄霧或塵埃的畫面；若要讓影像模型理解場景，可以直接描述光束、霧氣、塵埃與光源位置。

```text
古老教堂的彩繪玻璃窗透進金色陽光，空氣中有薄霧與細微塵埃，數道清楚可見的體積光束落在中央石製祭壇上，氛圍安靜而神聖。
```

### 04｜蝴蝶光：優雅、精緻的人像

主光放在人物正前方、略高於眼睛的位置，再往下照。鼻子下方通常會出現小型蝴蝶狀陰影，因此也稱為 Paramount Lighting。常見於美妝、時尚與形象照。

```text
時尚女性站在攝影棚中，主光位於鏡頭正前方略高處，臉部受光對稱，鼻子下方形成小型蝴蝶狀陰影，顴骨輪廓自然清楚，搭配柔和下方補光。
```

### 05｜柔光：親切、自然與療癒

柔光的陰影邊緣較模糊，明暗過渡平順。窗簾後的日光、陰天的天空，常能呈現這種效果。適合日常生活、人物特寫、品牌形象或講師影片。

```text
一位年輕女性坐在窗邊閱讀，陰天自然光穿過白色薄紗窗簾照亮臉部，陰影柔和、明暗過渡平順，保留自然膚質細節。
```

### 06｜硬光：力量、衝突與張力

硬光會形成邊界清楚的陰影，例如直射陽光或小型光源直接照射。它能突出輪廓與材質，適合格鬥、運動、街頭風格或強烈個性的角色。

```text
拳擊手站在昏暗拳擊場中央，左上方硬質聚光燈照亮臉部與肩膀，形成清楚銳利的陰影，汗水反射高光，畫面充滿力量與張力。
```

### 07｜側光：立體、沉思與故事感

光從人物側面照來，讓臉部一側受光、另一側留在陰影裡。側光可以是柔和的，也可以很銳利；不代表一定要把半張臉壓暗。適合訪談、人物獨白、紀實影像或懸疑短片。

```text
白髮老人坐在木屋窗邊看信，午後陽光從畫面右側照入，照亮右側臉頰與手部，左側保留柔和陰影，鼻樑和顴骨呈現自然層次。
```

### 08｜底光：不安、詭異與超自然

光源在人物下方時，鼻子、眉骨與臉部陰影會違反日常熟悉的光線方向，容易產生不安感。常用於恐怖片、驚悚短影音或超自然題材。

```text
年輕女子獨自站在黑暗房間裡，手持位於胸口下方的冷白色手電筒，光由下往上照亮臉部，眉骨與鼻子形成反常陰影，背景幾乎全黑。
```

## 把光線混搭，畫面會更具體

先選擇一種方向，再搭配光線質地和色彩，就能組合出更明確的視覺效果：

| 光線組合 | 畫面感受 | 常見情境 |
|---|---|---|
| 蝴蝶光＋柔光 | 精緻、親切 | AI 講師、美妝人像 |
| 側光＋柔光 | 自然、有層次 | 訪談、情感故事 |
| 逆光＋柔和補光 | 輪廓鮮明、仍看得清人物 | 夕陽、英雄登場 |
| 側光＋體積光 | 空間感、可見光束 | 森林、古堡、教堂 |
| 頂光＋硬光 | 明暗銳利、壓迫 | 懸疑、審問場景 |
| 底光＋冷色 | 詭異、不安 | 恐怖、超自然題材 |

例如生成仙俠人物時，可以寫「夕陽從人物身後形成逆光，金色體積光束穿過雲海與薄霧，臉部保留少量柔和補光，衣袍邊緣有明亮輪廓」，比只寫「丁達爾光、電影感」更容易讓畫面方向清楚。

## 三點布光：安排主光、補光與輪廓光

三點布光（Three-Point Lighting）是人物訪談、廣告和影像製作常見的基本配置，三個光源各有工作：

- **主光（Key Light）**：主要照亮人物，決定臉部立體感與主要光線方向。
- **補光（Fill Light）**：減輕主光形成的陰影，但不必把陰影完全消掉。
- **背光／輪廓光（Back Light／Rim Light）**：從人物後方勾勒頭髮或肩膀，幫助人物與背景分開。

新手可先從主光放在人物斜前方、略高於眼睛的位置開始，再用較弱的補光保留陰影細節，最後視需要加一點背後輪廓光。角度不是硬性規定，還是要依人物、背景與想要的效果調整。

三點布光不代表一定要買三盞燈：窗戶可以當主光，白牆或反光板可以補光，畫面裡的檯燈也可能成為合理的實景光源。ARRI 的燈光手冊也將 Key、Fill、Separation 與 Background 列為人物布光中不同的工作角色，可參考其[燈光手冊](https://www.arri.com/resource/blob/83996/409091c612f371b0c68b41d9dcb636db/arri-lighting-handbook-english-data.pdf)。

```text
一位成熟穩重的男性講師站在攝影棚內。左前方略高處的大型柔光源作為主光，照亮臉部；右前方較弱的補光保留自然陰影；人物後上方有微弱輪廓光，勾勒頭髮與肩膀，讓人物和深灰背景分開。中近景，直式構圖，膚質自然。
```

## 七種值得認識的人像布光模式

人像布光模式看的是光線在臉上形成的影子，而不只是燈架放在哪裡。除了前面介紹的蝴蝶光，以下幾種也很實用。

### 倫勃朗光（Rembrandt Lighting）

主光從人物斜前上方照來，暗側臉頰、眼睛下方會留下一塊小三角形亮區。它常用於成熟、有戲劇感的人像。只有「半張臉亮、半張臉暗」還不足以稱為倫勃朗光，需看三角形亮區是否出現。

```text
成熟男性坐在深色背景前，暖色主光從右前上方照射，暗側眼睛下方保留清楚的小三角形亮區，陰影深邃但仍有細節，呈現古典人像光影。
```

### 環形光（Loop Lighting）

主光通常在人物斜前上方，鼻子旁會形成一小段彎曲、沒有連到臉頰大陰影的鼻影。這裡的 Loop Lighting 指的是人像布光，不是直播常用的 Ring Light 圓環燈。

### 分割光（Split Lighting）

光線從接近人物正側面的位置照來，讓臉部兩側形成明顯明暗分界。它比一般側光更戲劇化，常用於神秘或情緒強烈的角色。

### 寬面光與窄面光（Broad／Short Lighting）

這兩種布光要看人物臉部朝向鏡頭的角度，以及哪一側受光。寬面光照亮較朝向鏡頭、可見面積較大的那側；窄面光則照亮較遠離鏡頭、可見面積較小的一側，常用來增加立體感。它們描述的是受光面和鏡頭的關係，不是光線軟硬或人物臉型。

### 蛤殼式布光（Clamshell Lighting）

主光放在人物正前上方，補光或反光板放在正前下方，從側面看像打開的蛤殼。這種安排能柔化眼下、鼻下與下巴的陰影，常見於美妝和精緻人像。

| 模式 | 觀察重點 | 可先嘗試的情境 |
|---|---|---|
| 蝴蝶光 | 鼻子正下方的小陰影 | 美妝、形象照 |
| 環形光 | 鼻子側下方的短鼻影 | 自然人像 |
| 倫勃朗光 | 暗側眼睛下方的三角亮區 | 戲劇人像 |
| 分割光 | 臉部明暗分界明顯 | 懸疑、角色照 |
| 寬面光 | 朝向鏡頭的較大臉部受光 | 明亮、開放的人像 |
| 窄面光 | 遠離鏡頭的較小臉部受光 | 立體、有張力的人像 |
| 蛤殼式布光 | 上方主光、下方補光 | 美妝、精品人像 |

## 延伸的電影打光術語

先知道術語在解決什麼問題即可，不必一次全背起來：

| 術語 | 白話說明 | 常見用途 |
|---|---|---|
| 輪廓光（Rim Light） | 讓人物邊緣受光，與背景分開 | 人像、登場畫面 |
| 高調照明（High-Key） | 整體明亮、暗部相對少 | 廣告、清爽人像 |
| 低調照明（Low-Key） | 以暗部為主，控制局部受光 | 懸疑、黑色電影 |
| 明暗對照（Chiaroscuro） | 用強烈明暗塑造立體與戲劇性 | 古典或戲劇人像 |
| 實景光源（Practical Light） | 畫面中看得到的燈、蠟燭或手機 | 室內劇情場景 |
| 動機式打光（Motivated Lighting） | 讓光線看起來有合理來源 | 寫實影像 |
| 負補光（Negative Fill） | 用黑布或黑板減少反射光，讓陰影更深 | 戲劇人像 |
| 反射補光（Bounce Lighting） | 把現有光反射回人物 | 自然人像 |
| 遮光造影（Gobo） | 遮住部分光線，投出窗格或樹影 | 場景氣氛 |
| 光比（Lighting Ratio） | 比較亮部與暗部的明暗關係 | 人像控制 |
| 光線衰減（Light Falloff） | 光線隨距離改變而變弱 | 空間與局部照明 |
| 眼神光（Catchlight） | 眼睛表面反射出的光點 | 人像特寫 |
| 體積光（Volumetric Lighting） | 光在霧、塵等介質中形成可見光束 | 森林、奇幻場景 |
| 黃金時刻（Golden Hour） | 日出後或日落前的低角度陽光 | 旅行、愛情影像 |
| 藍色時刻（Blue Hour） | 日出前或日落後的藍調時段 | 夜景、城市影像 |

高調不等於過曝，低調也不等於把整張圖直接調暗；兩者都要保留有意識的明暗安排。負補光不是「黑色的燈」，而是利用深色表面減少環境反射。冷色螢幕光搭配暖色檯燈，也能形成有層次的冷暖對比。

丁達爾效應的基本原理是光被懸浮微粒散射。若想了解這個物理現象，可參考[愛荷華大學的丁達爾實驗說明](https://instructional-resources.physics.uiowa.edu/6h5020-polarization-tyndall-experiment)；若是在 AI 提示詞描述電影畫面，通常直接寫「薄霧中的體積光束」會更具體。

## 把攝影知識寫進 AI 提示詞

可以用這個公式整理提示詞：

**人物與場景＋光源位置＋光線軟硬＋陰影效果＋色彩＋情緒氛圍**

例如，不只寫「一位男性坐在辦公室，電影級打光」，而是補充光從哪裡來、照亮哪一側，以及另一側要留下什麼陰影：

```text
一位成熟男性坐在深色辦公室內，午後柔和自然光從人物左前方的窗戶照入，照亮左半邊臉，右側臉頰保留細膩陰影；背景檯燈提供溫暖輔助光，整體沉穩、專業，像電影訪談畫面。
```

AI 不會真的拿尺測量 45 度，實際陰影也不一定完全符合指定方向。因此，重要要求最好同時寫「光源方向」與「臉上要出現的陰影」，再依生成結果修正。

### 文生圖和圖生影片要寫不同重點

文生圖需要描述人物、場景、光線、構圖與風格。圖生影片則已經有首幀提供人物外觀、場景和大致光線，提示詞可以把更多篇幅放在動作、運鏡和時間變化，並提醒模型延續原圖的光線特徵：

```text
10 秒寫實電影短片，一鏡到底。男性原本低頭沉思，緩慢抬起頭並望向鏡頭，目光逐漸堅定。鏡頭從中近景緩慢向前推進，最後停在臉部特寫。延續原始畫面的主光方向與倫勃朗光影，保持人物五官和服裝一致，動作自然、微表情細膩。
```

## 新手實戰：同一個人物比較八種打光

一次只改變光線，其他條件盡量維持一致，才看得出光線本身造成的差異。

### 步驟一：準備固定的角色參考圖

可以使用自己有權使用的形象照，或先生成一位固定的虛擬人物。正面或接近正面的半身照、簡單背景，會比較方便觀察光線變化。

### 步驟二：請 AI 先規劃提示詞

```text
請參考我提供的角色圖片，盡量保持人物五官、髮型、服裝、拍攝角度與背景一致。

我要比較八種電影打光：頂光、逆光、體積光、蝴蝶光、柔光、硬光、側光、底光。請先為每一種列出光源位置、陰影特徵與情緒方向，再一次生成一個版本，方便比較。
```

不同工具對角色參考與提示詞的遵循程度可能不同；如果人物、背景也一起改變，先簡化要求，讓比較條件盡量接近。

### 步驟三：觀察光線，不只挑最漂亮的一張

- 光大致從哪個方向來？
- 哪一側臉比較亮，鼻子和下巴的陰影怎麼變？
- 陰影邊緣是柔和還是銳利？
- 背景有沒有被照亮？
- 不看表情，光線本身帶來什麼情緒？

### 步驟四：再比較人像布光模式

使用同一角色，分別嘗試三點布光、倫勃朗光、環形光、分割光、高調與低調照明，觀察它們在臉部形成的差異。

### 步驟五：挑三種光線做短片

從靜態圖中挑三種效果，分別生成 5 至 10 秒短片。先不要要求同一支影片不斷切換八種光線，因為模型還要處理人物動作、運鏡、場景與時間變化；拆開練習會比較容易找到問題來源。

## 想繼續學，可以按四個階段練習

1. **看懂光線**：從頂光、側光、逆光、底光、柔光與硬光開始，練習判斷光源方向和陰影位置。
2. **安排光線**：認識主光、補光、輪廓光、三點布光與基本光比，理解每道光各自的作用。
3. **用光設計情緒**：練習倫勃朗光、環形光、分割光、蝴蝶光、高調與低調照明。
4. **用光說故事**：進一步觀察動機式打光、實景光源、冷暖色對比、體積光、負補光，以及鏡頭之間的光線連續性。

可以延伸搜尋 `Three-Point Lighting Tutorial`、`Rembrandt Lighting Photography`、`Portrait Lighting Patterns`、`Cinematic Lighting for Beginners`、`Motivated Lighting Cinematography` 等英文關鍵字，搭配燈位示範和前後比較來練習。若想延伸到運鏡與鏡頭描述，也可以閱讀[AI 攝影語言與 Google Flow 運鏡提示詞](/posts/ai-cinematography-prompts/)；想從故事角度規劃影片，則可參考[AI 影片故事與敘事能力](/posts/ai-video-storytelling/)。

以前談 AI 影片，常常先比模型、工具與提示詞。現在生成門檻降低了，我反而覺得攝影、打光、構圖、色彩、運鏡和故事節奏更值得補上。新手不必先背完名詞，可以從看懂光開始，再練習如何安排光線、用光表達情緒。

當你知道光從哪裡來、陰影應該落在哪裡，以及這道光想說什麼故事，你就不只是叫 AI 生成影片，而是在學影像創作。

## 常見問答 (FAQ)

### Q1：為什麼寫了倫勃朗光，AI 卻沒有生成三角形亮區？

模型可能只抓到「強烈明暗對比」，沒有準確還原臉部陰影結構。可以補充「人物暗側眼睛下方保留一塊清楚的小型三角形亮區」，並先用靜態圖片確認光影，再拿來生成影片。

### Q2：AI 人像看起來像塑膠娃娃，改善打光就夠了嗎？

不一定。柔和側前光、自然陰影和真實皮膚紋理可能有幫助，但臉部細節、生成模型特性與後製也會影響真實感；打光不是唯一因素。

### Q3：為什麼圖生影片後，人物臉上的光線會變來變去？

影片生成時，模型可能無法在角色轉頭、移動或運鏡後穩定維持光線方向。可以先減少大幅度轉頭與運鏡，並保持簡單明確的光源設定；若情節需要明顯從白天轉夜晚，可拆成不同鏡頭處理。

### Q4：一定要用英文提示詞，AI 才懂打光嗎？

不一定。可以先用中文說清楚場景、光源方向和陰影，再補上必要的英文術語，例如 `Rembrandt Lighting`、`Soft Light` 或 `Volumetric Lighting`。若效果不理想，再把關鍵句改成英文比較。

### Q5：學會三點布光後，所有影片都應該用三點布光嗎？

不是。三點布光適合建立清楚、穩定的人物照明，但有些故事需要保留大量陰影、只用自然窗光，甚至不補光。攝影知識是幫助你判斷何時用光，也知道何時應該把光拿掉。
